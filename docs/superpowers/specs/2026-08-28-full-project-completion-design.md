# 全项目交互课程补全设计

日期：2026-08-28

## 目标

在保留现有 118 道算法题、71 个 AI 专用可视化和 CUDA VectorAdd 专用可视化的前提下，补齐所有仍显示占位页或没有可视化入口的内容：

- AI：补齐 `10072-10134`，共 63 题。
- CUDA：补齐除 `101` 外的 21 题。
- 计算机基础书架：为 6 本书各新增 6 个核心概念，共 36 个概念。
- DRL：保留已有 36 课，并把教学流程升级为每个数据流关节都可独立点击回看。

最终页面不再出现“正在开发中”或“待实现”的正常数据分支。

## 已选方案

采用“每题独立教学蓝图 + 领域共享渲染器”。每个题目保存独立的标题、直觉、公式、符号解释、数据流、误区、调试提示和总结；AI、CUDA、概念课程共享一套稳定的交互外壳。已有高定制可视化继续优先使用，新内容走教学蓝图渲染器。

该方案比复制 120 套 React 状态机更容易验证和维护，同时仍保证每个题目的知识内容独立。共享仅限播放、步骤跳转、公式容器和响应式布局，不共享题目知识文本。

## 教学节奏

每个新条目都按同一套适合初学者的顺序展开：

1. 用现实类比建立直觉。
2. 逐个解释公式符号。
3. 展示可由 KaTeX 严格解析的核心公式。
4. 将数据流中的每个关节拆为可点击步骤。
5. 解释常见误区，并给出可执行的调试检查方法。
6. 用一句话总结。

播放控制器保留播放、暂停、前后跳转、重置、速度调整，并提供横向步骤时间线。时间线上的每一个关节都可直接点击，不依赖线性播放。

概念 ID 使用 `40001-40036`，避开算法、AI、CUDA 与 DRL 现有编号。

- 数据结构与算法：数组与局部性、链表、栈与队列、树遍历、图搜索、动态规划。

## 模块边界

- `guidedLessonTypes.ts`：唯一的教学蓝图和步骤协议，保持为纯 TypeScript，便于 Node 契约测试。
- `aiLessonBlueprints/*`、`cudaLessonBlueprints/*`、`conceptLessonBlueprints/*`：按领域分片，避免多人编辑冲突。
- `GuidedLessonVisualizer.tsx`：只负责呈现，不包含题目知识。
- 三个轻量包装器：根据路由 ID 解析对应蓝图。
- 注册表：已有专用组件优先，缺失 ID 回退到对应共享教学组件。
- 概念数据：由概念课程记录生成列表元数据，避免列表和详情内容漂移。

## 异常处理

- 无效 ID 显示明确的“内容不存在”状态，并保留返回入口。
- 蓝图查找失败返回空步骤，不让播放控制器访问越界。
- 长公式放在横向滚动容器内，KaTeX 使用严格测试提前拦截无效语法。
- 移动端详情页改为纵向内容流，桌面端保持描述与可视化双栏。

## 质量与审查

机器门禁：

- 每个目标 ID 恰好有一份蓝图。
- 每份蓝图具备完整字段、至少两个符号、至少三个数据流关节和调试提示。
- 每条公式均通过 KaTeX `throwOnError: true` 渲染。
- 每个数据流关节对应一个可直接跳转的交互步骤。
- 六本书各有六个概念，ID、slug 唯一。
- 单测、TypeScript 构建、ESLint 和浏览器端到端流程通过。

人工/代理门禁：实现代理按分片交付；独立 reviewer 对分片内每个 ID 分别记录“易读、易学、易调试、公式正确、步骤连贯”的结论。主代理仅在修复阻断项后集成。

## 浏览器验收

桌面和移动视口至少覆盖 AI、CUDA、概念、DRL 各一条课程。每条课程检查：公式可见、步骤时间线可点击、前后跳转生效、最终总结可达、无文字遮挡、无控制台错误。概念首页还需显示 `36` 个概念，六本书均可进入。
